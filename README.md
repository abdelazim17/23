# ترولي ماركت — الملف الرئيسي

## الرفع على GitHub
1. اسحب **كل** الملفات + فولدر `images` (Add file ← Upload files ← Commit).
2. Settings ← Pages ← Branch: main / root ← Save.

## شكل الملفات (مهم)
```
index.html  app.js  fx.js  style.css  sw.js  _headers  manifest.webmanifest  xlsx.full.min.js
data.xlsx
images/     ← كل الصور هنا في فولدر واحد من غير فولدرات جواه
```

## التحكم من الإكسل
- عمود **عروض اليوم** = نعم يظهر المنتج في عروض اليوم (مفيش شيت عروض منفصل).
- `data.xlsx`: ملف واحد فيه كل حاجة — شيتات الإعدادات (عام، الألوان، التواصل والفوتر، الطلب والدفع، الهيرو والرئيسية، المنتجات، صفحة حول) ثم شيتات الواجهة (إدارة الأقسام، السلايدر، البنرات، أقسام سريعة، مجلة العروض، باقات العروض) ثم شيت لكل قسم منتجات. ابدأ من شيت «دليل الاستخدام».

## الأنواع والأسعار
في آخر كل شيت منتجات 10 أنواع: «نوع 1» و«سعر 1» ... «نوع 10» و«سعر 10». اكتب النوع (ربع كيلو، نص كيلو، جبنة...) وسعره جنبه. نوع من غير سعر بياخد «السعر الأساسي». لو الأنواع فاضية مفيش قايمة. المنتج بالكيلو من غير أنواع بيمشي ¼ ½ 1 1½ تلقائي.

## التوصيل ونطاق الشغل
شيت «الطلب والدفع»: رسوم التوصيل (5)، رسوم الطلب التقيل (10) وحده بالكيلو (2)، حد التوصيل المجاني (100)، الحد الأدنى (0 = مفيش)، و«نطاق التوصيل» (بيظهر في السلة وتحت في الموقع).

## إخفاء قسم
«إدارة الأقسام» ← ظاهر: **نعم** عادي | **غير متوفر** باهت ومنتجاته مش بتتباع | **لا** يختفي من الموقع كله (الرئيسية، الأقسام، البحث، العروض، الباقات، السلايدر، البنرات، الأقسام السريعة).

## الصور
- كل المنتجات بتستخدم صورة واحدة `images/product.svg` (من إعداد «صورة المنتج الافتراضية»). لو عايز صورة حقيقية لمنتج اكتب مسارها في عمود «صورة».
- لكل بنر وسلايدر وقسم سريع وصفحة مجلة وأيقونة الموقع صورة خاصة (موجودة في `images`).
- للتغيير: ارفع الصورة الجديدة بنفس الاسم، أو غيّر المسار في الإكسل.

## مقاسات الصور
| الصورة | المقاس |
|---|---|
| السلايدر | 1200 × 600 (بيتقص 3:1 على الكمبيوتر، فخلّي الكلام في النص) |
| البنر العلوي والسفلي | 1200 × 600 (بيتقص 3:1 على الكمبيوتر) |
| البنرين المقسومين | 800 × 400 (4 بنرات متساوية، صفين) |
| الهيرو (كمبيوتر) | 1600 × 900 (نسبة 16:9) |
| الهيرو (موبايل) | 800 × 1000 (نسبة 4:5) |
| الأقسام السريعة | 400 × 400 |
| المنتج | 600 × 600 (حد أقصى 800) |
| صفحة المجلة | 800 × 1130 |
| صفحة حول | 800 × 500 |
| أيقونة الموقع | 512 × 512 |
| صورة المشاركة `share.png` | 1200 × 630 |
الكلام على السلايدر والبنرات بيتكتب من الإكسل على الجانب **الأيمن**، فخلّي الأيمن هادي.

## فحص الأخطاء
افتح الموقع بإضافة `?check=1` في آخر الرابط — هيطلع لك قايمة بأي سعر ناقص أو اسم مكرر أو صورة مش موجودة أو باقة فيها منتج غلط.

## مشاركة الرابط على واتساب
في `index.html` الوسم `og:image` مكتوب بمسار نسبي. لما الدومين النهائي يتحدد غيّره للرابط الكامل (مثال `https://دومينك/images/share.png`) عشان صورة المعاينة تظهر.

## الطلبات
> الموقع بيبعت الطلب للجدول عبر رابط `/exec` (رابط اختياري، لو فاضي الطلب يروح واتساب بس). وتاب «لصق الطلبات» في الجدول بديل احتياطي للطلبات اللي جت واتساب من برّه الموقع. ولو الجدول وقّف الاستقبال الموقع بيحتفظ بالطلب ويعيد المحاولة.
> وضع «رابط الفاتورة + النص» مقفول حاليًا في الكود (بيرجع لـ «نص فقط») لحد ما السكريبت يدعمه. ملف السكريبت `Code.gs` بيتلصق في Apps Script لوحده (مش جوه الموقع).

`data.xlsx` ← «الطلب والدفع» ← «طريقة إرسال الطلب»: نص فقط (الأسرع) / مشاركة الصورة. («رابط الفاتورة + النص» غير متاح حاليًا وبيرجع لـ «نص فقط».) شيت الطلبات (Google Sheet) منفصل ورابطه `/exec` في «رابط تسجيل الطلبات».

| الاستخدام | اللون |
|---|---|
| برتقالي (الأزرار والأسعار) | `#DE5718` |
| بني (العناوين والفوتر) | `#5A3114` |
| بني غامق (النص) | `#3B2410` |
| أصفر (الخصم و«مضاف») | `#F9B914` |
| بيج (لمسات الخلفية والأقسام) | `#F4F1E9` |
| أبيض (خلفية الموقع) | `#FFFFFF` |

**التصميم الزجاجي (معتمد):** الكروت والأزرار والمدخلات شبه شفافة بلمعة بيضاء وحدود فاتحة وظل ملوّن خفيف فوق بقع لون ناعمة ثابتة في الخلفية. تأثير الضبابية (`backdrop-filter`) على الشريط العلوي والسفلي بس، عشان السكرول يفضل خفيف. أي كارت جديد يستخدم نفس المتغيرات `--g-bg` و`--g-brd` و`--g-sh` في آخر `style.css`.

## الأقسام من الإكسل (data.xlsx ← إدارة الأقسام)
| العمود | الشرح |
|---|---|
| القسم | اسم الشيت في data.xlsx (مفتاح، ما تغيّرهوش لوحده) |
| الاسم المعروض | الاسم اللي بيشوفه الزبون — غيّره براحتك |
| ظاهر | نعم / غير متوفر / لا |
| الترتيب | 1 = الأول |
| اللون | لون شريط القسم |
| أيقونة | اسم أيقونة FontAwesome من غير fa- (fontawesome.com/search?o=r&m=free) |
| صورة | لو اتكتب مسار صورة (images/cat-fruits.svg) بتتعرض بدل الأيقونة. الأيقونات الجاهزة: images/cat-*.svg |

- قسم جديد: شيت جديد في data.xlsx + سطر في «إدارة الأقسام».
- شكل البحث: data.xlsx ← «عام» ← «شكل البحث» (كبسولة / أيقونة).
## الأمان
- ملف `_headers` (بيشتغل على Cloudflare Pages بس، مش على GitHub Pages) فيه: سياسة CSP مشدّدة (سكربتات من الموقع نفسه بس)، منع الـiframe، `nosniff`. عشان كده `xlsx.full.min.js` لازم يفضل في نفس الفولدر باسمه ده بالظبط (مفيش احتياطي من CDN).
- **الموقع معتمد على نفسه بالكامل:** الخطوط (Cairo وBaloo Bhaijaan 2) وأيقونات Font Awesome جوه فولدر `fonts/` (تراخيصها OFL وCC BY 4.0 جنب الملفات)، ومكتبة الإكسل `xlsx.full.min.js` محلية. (أيقونات Font Awesome المتاحة: Solid وBrands بس، مفيش Regular — لو كتبت `far` في عمود أيقونة مش هتظهر.) مفيش أي طلب لـGoogle أو cdnjs، وسياسة CSP بتمنع أي حاجة من برّه. **مهم:** ارفع فولدر `fonts` كامل مع الموقع، ولو غيّرت ملف جواه بنفس الاسم غيّر رقم `?v=` في `index.html` (الكاش بتاعه سنة).
- حسابات Google وGitHub وCloudflare: فعّل مفتاح المرور (Passkey) أو التحقق بخطوتين، وخلي الشيت وفولدر النسخ الاحتياطية Restricted.
- أكّد كل طلب على واتساب قبل التجهيز (الأسعار بتيجي من متصفح الزبون وبتتحذّر بس).
- صور الأقسام `cat-*` مقاسها 400×400 (1:1) زي الأقسام السريعة.
